## Сохранность данных

Пользователь отдельно сообщил о пропаже данных и некликабельных кнопках после запусков/переноса папки. Это ключевая регрессия, которую нельзя возвращать.

- Рабочий snapshot: `.materials-workspace/workspace.json`, исключён из Git. Также используется ключ `materials.projectWorkspace.v1` в localStorage.
- Главная страница имеет `ssr: false`: это ранее устраняло hydration mismatch между сервером и браузерными данными.
- Loader ждёт snapshot перед монтированием интерфейса. После аудита серверная версия имеет приоритет над устаревшим localStorage; отличающаяся копия сохраняется для восстановления. Pending offline-копия автоматически восстанавливается только при совпадении её базовой серверной ревизии. Обычное открытие страницы не запускает save.
- Смена порта/host меняет origin и localStorage. Использовать постоянный адрес с `127.0.0.1`, не менять его на localhost без необходимости.
- В аудите 14.10.2026 исправлены проглатывание ошибок чтения, безусловная запись при открытии, гонки сохранения и перезапись свежих данных устаревшей вкладкой. Используются проверка версии, атомарная замена файла и очередь. Ошибки/конфликты видны в интерфейсе; доступно скачивание копии и retry временной ошибки. URL-сброс удалён. Подробности и ограничения — в отчёте аудита.
- Не открывать `?reset=1`, не очищать браузерное хранилище, не выполнять seed/reset/миграции ради запуска. Резервную копию и тестовые данные хранить отдельно от рабочего snapshot, вне Git.
- Docker Compose описывает материалы на 55432 и тестовую БД на 5433. Главный рабочий интерфейс сейчас читает snapshot; наличие Drizzle/PostgreSQL не означает, что все процессы уже переведены на БД. Миграции/изменение БД — только по отдельному разрешению.

- В «Общих данных» исправляли сортировку записей одной даты: новые заявки/получения/ВК добавляются в начало массивов, более свежие действия должны поднимать соответствующие позиции выше.

- В модалке «Заявка на получение» под поиском добавлены «Все / Заполненные». Заполненной считается позиция с количеством по заявке больше нуля.
- Пользователь просил проверить, не утрачены ли прошлые функции; сохранность функциональности и незакоммиченных правок особенно важна.
